# Source timetable screenshots

These two images were shipping inside `public/images/` and being deployed as web assets,
but they are not photographs — they are screenshots of the gym's class grid.

They are kept here as **reference material**, not site content. Use them to verify the
hardcoded timetable in `src/pages/timetable.astro` and the seed data in `schema.sql`,
which are currently maintained by hand and have never been checked against these.
