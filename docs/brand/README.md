# Brand assets

`xfc-logo-2024-v3-FINAL.ai` is the master logo supplied by the business (Aug 2026) —
the 2024 roundel whose ring reads "KICKBOXING · MMA · BJJ · BOXING" (the earlier
"Australian Top Team · Mixed Martial Arts" version is retired). All site logo assets
(`/images/xfc-logo.png`, `favicon.ico`, `favicon.png`, `favicon.svg`) are rendered from
this file. It is an Illustrator file with a PDF-compatible stream; re-render with
pypdfium2 at scale if new sizes are needed.
